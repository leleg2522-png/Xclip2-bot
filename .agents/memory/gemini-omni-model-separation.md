---
name: Gemini Omni model separation
description: Keeps the legacy Gemini Omni and the Picsart gateway Omni 1.2 product routes distinct.
---

Gemini Omni 1.2 must remain an additional model, not a replacement for the legacy Gemini Omni model. Keep separate menu entries, prices, routing, and provider contracts.

**Why:** The user explicitly requires the existing model to remain available while Omni 1.2 is added with its own 360p/10-second contract and price.

**How to apply:** Any Gemini Omni menu, pricing, payload, or routing change must identify which product variant it targets and preserve the other variant unchanged.
