## Product decision

The public Kling 2.1 P2 is a 10-second, single-image image-to-video product,
not the separate Kling Motion Control P2 package. The user selected Alriz
Kling 2.5 Turbo at 1080p (1,000 Alriz credits per generation).

Keep the customer-facing Kling 2.1 P2 label and Rp3,000 tariff unless the user
changes them. Use the existing database-managed Alriz key pool.

**Why:** After upload failures on the previous backend, the user asked to move
this product to Kling 2.5 through Alriz, first choosing 720p and then changing
the output choice to 1080p.

**How to apply:** Keep the I2V product separate from Motion Control P2. Refund
any failed or undelivered generation. After an accepted or ambiguous submit,
never create another paid job; continue polling the accepted job ID or refund.
