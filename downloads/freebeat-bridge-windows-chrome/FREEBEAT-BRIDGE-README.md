# Freebeat Bridge Windows

1. Install **Node.js 20 atau lebih baru** dan **Google Chrome** di Windows.
2. Salin folder `local-runner` ini ke PC Windows.
3. Di Telegram, sebagai admin, jalankan `/bridgecode`.
4. Klik dua kali `freebeat-bridge.bat`.
5. Masukkan URL Railway bot dan kode yang dikirim bot.
6. Login Freebeat di jendela Google Chrome yang terbuka, lalu biarkan program berjalan.

Bridge tidak memerlukan port forwarding atau IP publik. Browser Freebeat selalu terlihat
di PC dan data sesi browser tidak dikirim ke Railway.

Jika browser meminta login ulang, login kembali lalu refresh halaman generator video.
